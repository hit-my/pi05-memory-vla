# real_robot_blocks：真机"杯子与数字方块"任务的数据处理、标注与部署

面向 ACT 格式的 hdf5 示范（双臂 Dobot，只有右臂动）。任务：桌上三个倒扣的杯子、三个数字方块（0、1、2）和一个盘子；依次拿起每个杯子看下面有没有粉色小方块，放回，最后把"数字等于看到的方块数"的那个数字方块放到盘子上。杯子放回后下面的情况就看不见了，所以数量必须靠模型写下的记忆来保持。

结构和 `real_robot/`（碗任务）相同，约定全部写在 `real_spec.py` 里。不同之处如下。

## 六个实体

追踪并写进 Action 行的物体共 6 个：远杯、中杯、近杯、0 号方块、1 号方块、2 号方块。训练代码的实体槽位因此要从 3 改成 6，共两处，各一行：

- `memory_format.py`：`MAX_ENTITIES = 6`
- `joint_model.py`：配置里的 `max_entities: int = 6`

只改第一处时，数据检查（`real_check.py`）能通过，但训练第一步会因形状不匹配报错。

## 清单与标注（全部由规则生成，没有人工或模型复核）

每条示范 11 项：每个杯子"lift → 观察结果（has block / empty）→ put back"，然后"pick up block N"、"place the block on the plate"。

- 各项的起止由**夹爪指令**切分（示范必须是闭合/张开各 4 次；不满足的示范被 `real_extract.py` 丢弃并写明原因）。
- 观察结果是清单里单独的一项，在杯下区域露出来的那一帧才写入并打勾（`causal_labels.with_observations`）；有无方块由颜色检测粉色小方块得到，并要求"检测到的数量 = 最后被拿走的数字方块"，不一致的示范被丢弃。
- "pick up block N" 在各条示范里不同，所以在它开始之前清单里显示为 `?`；决定 N 的信息这时已经在清单里了。
- 验证集每种答案取 2 条（`VAL_EPISODES`），不是最后几条（那几条答案全是 0）。

## 追踪器（`real_tracker.py`，标注和部署共用同一份代码）

首帧：SAM3 文本检测，杯子和方块各用几个提示词，再分别选出"竖排成一列"的三个（只用 "cup" 一个提示词时，倒扣的杯子在俯视图里经常检不全）。

之后是 SAM3 视频追踪，但**不直接报告掩码中心**：机械臂经过静止物体上方时，露出的掩码缩到一侧或漏到夹爪上，中心会跟着机械臂滑动，画出一条不存在的轨迹。规则是：

- 物体默认"静止"，报告它上次停稳时的中心，被遮挡多少都不变；可见像素太少时不报告（不画）。
- 只有夹爪被指令闭合期间，物体才可能被认定为"被拿起"：掩码中心离开原位（杯子 20 像素、方块 10 像素）、大部分掩码已不在原位、掩码颜色仍是该物体的颜色，连续 4 帧满足；每次闭合只认定一个。
- 夹爪张开后，等掩码稳定 8 帧，记为新的静止位置；夹爪移开、物体露出更多后再校准一次。

因此追踪器每帧需要知道夹爪是否被指令闭合：标注时取录下来的指令，部署时取上一步执行的动作（`real_deploy.py` / `real_deploy_async.py` 已传入并记入日志）。

`real_track.py` 会把 SAM3 的原始掩码存下来，规则改动后用 `real_rules.py` 几秒钟即可重算轨迹，不必重跑追踪。

## 流程

```bash
bash real_robot_blocks/run_track.sh <hdf5 目录> <RAW> "0 1 2 3"      # 提取 + 追踪；路径变量见脚本开头，需按机器设置
python real_robot_blocks/real_qa.py <RAW>                             # 轨迹质检，必须全部通过
bash real_robot_blocks/run_build.sh <RAW> <DATASET> <6 实体的训练代码目录> <一份路径正确的方案 C 配置>
```

`real_qa.py` 检查：起始顺序；物体没被拿着时不动（偏离不超过 15 像素，画出的总路径不超过 30 像素）；每个杯子在自己的那次抓取中移动并回到原位附近；数量对应的数字方块在第 4 次抓取中被拿走，另外两个全程不动。

## 已知的不足

- 被拿起的头 20 帧左右，轨迹点还停在原位，随后直接连到当前位置。
- 放下后静止位置会校准一次，幅度多为 3–8 像素。
- 示范里藏方块的方式只有三种固定组合（远杯+中杯、只有远杯、都没有），模型可能学成按位置判断而不是计数。
- 部署脚本的调度逻辑有自测（`real_deploy_async_selftest.py`），但带真实追踪器和模型的端到端回放、以及真机运行都还没有做过。
